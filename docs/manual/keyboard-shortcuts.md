# Keyboard shortcuts

Every action is reachable from the keyboard. Keys written `Ctrl+Z` use `Ctrl` (⌘ on macOS where the menu shows it).
The keys of the grid and of the image view apply to the selected photos, or to the photo under the cursor.

## Anywhere

| Key | Action |
| --- | --- |
| `Ctrl+N` | New workspace |
| `Ctrl+O` | Open workspace |
| `Ctrl+,` | Settings |
| `Ctrl+I` | Import |
| `Ctrl+Q` | Quit |
| `F1` | About |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+A` | Select all (all photos in the grid, all the text in a field) |
| `Ctrl+Shift+A` | Select none |
| `Ctrl+Shift+I` | Invert the selection |
| `Ctrl+K` | Go to the keyword field |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V`, `Del` | Cut, copy, paste and delete in a text field |

`Alt` with a section's underlined letter (File, Edit, Help) opens that menu.

## In the grid

| Key | Action |
| --- | --- |
| `Left`, `Right`, `Up`, `Down` | Move the selection one photo; with `Shift`, extend it; with `Ctrl`, move the cursor only |
| `PageUp`, `PageDown` | Move a page |
| `Home`, `End` | First, last photo |
| `Space` | Add or remove the photo under the cursor |
| `Escape` | Clear the selection |
| `0` to `5` | Rate (`0` clears the stars): `0`, `1`, `2`, `3`, `4`, `5` |
| `P`, `X`, `U` | Pick, reject, clear the flag |
| `6`, `7`, `8`, `9` | Red, yellow, green, blue label (again to remove) |
| `Return` | Open in the image view |
| `E` | Open or close the series under the cursor |
| `R` | Resolve the series: keep the selected photos, reject the others |
| `Ctrl+G` | Group the selection as a series |
| `Ctrl+Shift+G` | Take the selection out of its series (or dissolve a closed series) |

## In the image view

| Key | Action |
| --- | --- |
| `Left`, `Right` | Previous, next photo (`Backspace` and `Space` do the same) |
| `Home`, `End` | First, last photo |
| `0` to `5`, `P`, `X`, `U`, `6` to `9` | The same ratings, flags and labels as in the grid |
| `Z` | Fit to the window, or show at 100 % |
| `+`, `-` | Zoom in, zoom out |
| `F` | Full screen (`F11` too) |
| `I` | Show or hide the information line |
| `T` | Show or hide the filmstrip |
| `A` | Auto-advance on or off |
| `Escape` | Back to the grid (`Return` too) |

## In the keyword panel

| Key | Action |
| --- | --- |
| `Ctrl+K` | Go to the field |
| `Enter` | Give the best match to the selected photos, or create the keyword |
| `Shift+Enter` | Create the keyword even when another one matches |
| `Escape` | Empty the field and go back to the grid |

## The mouse

- **Click** selects, **`Ctrl`+click** adds or removes, **`Shift`+click** selects a range, a **drag** on empty space
  is a rubber band, a **double click** opens the image view, a **right click** opens a photo's menu.
- In the image view the **wheel** zooms, a **drag** moves a zoomed photo, a **double click** switches between fit and
  100 %, a **right click** opens the menu.
- In the keyword panel a **drag** moves a keyword, and dragging its left edge resizes the panel.
